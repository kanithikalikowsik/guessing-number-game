# 🎯 Guess the Number Game

A simple and interactive number guessing game built using **HTML**, **CSS**, and **JavaScript**. The game generates a random number, and the player tries to guess it. The application provides feedback to help the player reach the correct answer.

## 🚀 Features

- 🎲 Random number generation
- 🔢 User input for guessing
- ✅ Displays correct and incorrect messages
- 📱 Responsive and easy-to-use interface
- ⚡ Built with vanilla JavaScript

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
